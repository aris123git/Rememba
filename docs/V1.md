# V1 — Périmètre exact (MVP)

Objectif : un produit **utilisable** pour tester le concept, pas une maquette.

## Inclus (logique réelle)

1. Application Android Flutter (même API que le web)
2. Inscription / connexion / déconnexion
2. Consentement d’analyse IA (requis pour visages, révocable)
3. Galerie paginée (miniatures, pas les originaux en masse)
4. Import multi-photos (disque, EXIF date/GPS si présents)
5. Affichage photo + visages détectés
6. Détection de visages (YuNet)
7. Embeddings (SFace)
8. Regroupement des visages similaires (cosine + union-find)
9. Identités locales (`Person`) créées à la confirmation
10. Validation manuelle : nommer, « c’est moi », ignorer, « plusieurs personnes »
11. Détection basique d’événements (proximité temporelle) sous forme de **suggestions**
12. Création manuelle d’événement + association / retrait de photos
13. UI « Vos souvenirs » + suggestions IA
14. Suppression photo, retrait d’événement, suppression de compte

## Exclu (TODO / FUTURE VERSION)

- Compte OAuth, 2FA
- App iOS native (même projet Flutter, build Xcode)
- Sync offline / traitement 100 % on-device
- Partage, invitations, événements collectifs
- Contacts
- Vidéo / musique / agent NLP
- Matching de visages **entre** utilisateurs
- Niveaux de confiance LOW/MEDIUM/HIGH dans l’UI (le champ existe en base pour V2)

## Critères d’acceptation

- Je crée un compte, j’importe des photos, je les vois dans la galerie.
- Si j’ai consenti, les visages sont détectés en arrière-plan (badge « analyse… » puis prêt).
- Plusieurs photos de la même personne proposent une identité à confirmer.
- Je nomme la personne : ses photos sont regroupées sous Personnes.
- Je crée un événement, j’y attache des photos, je peux en retirer une.
- Une rafale de photos horodatées proches propose un événement, sans le créer toute seule.
- Je supprime mon compte : plus de lignes ni de fichiers.
- Aucun bouton qui « fait semblant ».
